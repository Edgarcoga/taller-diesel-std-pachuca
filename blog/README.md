## Cómo Agregar Artículos (Futuro)

Esta carpeta está reservada para contenido de blog / artículos SEO.

### Ideas de artículos para posicionamiento local:

1. **"¿Cómo saber si mis inyectores diésel necesitan reparación?"**
   - Keywords: reparación inyectores, síntomas inyectores dañados

2. **"Reparación de sistemas Caterpillar C-9 en Pachuca"**
   - Keywords: Caterpillar C9, CAT C9 Pachuca, reparación CAT

3. **"¿Dónde reparar un turbo en Hidalgo?"**
   - Keywords: reparación turbo Hidalgo, turbo Pachuca

4. **"5 señales de que tu bomba de inyección necesita servicio"**
   - Keywords: bomba de inyección, servicio bomba diésel

5. **"Taller mecánico diésel cerca de mí — STD Pachuca"**
   - Keywords: taller diésel cerca de mí, mecánico diésel Pachuca

6. **"Diferencias entre inyectores common rail y convencionales"**
   - Keywords: inyectores common rail, inyectores convencionales

### Formato sugerido para cada post:
```
blog/
├── como-saber-si-inyectores-necesitan-reparacion.html
├── reparacion-caterpillar-c9-pachuca.html
└── donde-reparar-turbo-hidalgo.html
```

### Cada artículo debe incluir:
- Título con keyword principal
- Meta description con keyword + localidad
- Mínimo 800 palabras
- Imágenes con alt text descriptivo
- Link a la página de servicios y contacto
- Botón de WhatsApp al final
